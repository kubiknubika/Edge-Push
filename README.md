# КРАЙ / Edge Push

Пошаговая микро-тактика **непрямого боя** для одной руки в портретном мобильном браузере.
Каменный остров 5×5, 7 этажей, 2–3 минуты на забег. Прямых ударов нет: враги гибнут от
**толчков в пропасть, лаву, колонны, взрывные бочки и друг в друга**.

**Один файл `index.html` — вся игра.** Vanilla JS + DOM/CSS/SVG, без сборки, без библиотек,
без внешних ассетов, без сети. Работает даже по `file://` (просто откройте файл в браузере).

```bash
npm start          # python3 -m http.server 8000 → http://localhost:8000
npm test           # 59 автоматических тестов (движок + UI + обучение + легенда + палитра + масштаб + ИИ)
npm run ai         # обучить эволюционный ИИ, проверить проходимость, собрать отчёт
```

## Управление

| Действие | Как |
| --- | --- |
| Шаг / толчок щитом | Крестовина `▲ ▼ ◄ ►` **или свайп в любой точке экрана** (порог 30 px) |
| Крюк | Тап по кнопке (режим-переключатель), затем направление. Повторный тап отменяет |
| Бросок через плечо | Тап по кнопке, затем направление на врага/бочку перед героем |
| Ждать | Пропустить ход, получить +1 щит до начала следующего хода игрока |
| ▦ / ? | Легенда «кто есть кто» / правила (в справке — повтор обучения) |
| ↺ | Новый забег (с подтверждением) |
| Клавиатура | `←↑→↓` или `WASD`, `1` — крюк, `2` — бросок, `3`/`Space` — ждать, `L` — легенда, `R` — заново |

Нажимать на клетки поля **не нужно и нельзя**: весь ввод живёт в нижней эргономичной зоне,
поэтому тряска в транспорте не приводит к миссклику. Верхние 55% экрана — поле и статы,
нижние 45% — D-pad (кнопки ≥ 64 px) и три крупные кнопки приёмов с крупной цифрой отката.

## Обучение при первом запуске

При первом открытии игры поверх нижней части поля появляется компактная карточка с
**6 шагами**: цель, ход одной рукой, толчок, лимит `⚡` и телеграфы, три приёма, структура забега.
Нужные элементы пульсируют: крестовина, три кнопки приёмов или само поле.

- Шаги 2 и 3 — **интерактивные**: они завершаются автоматически, когда игрок делает реальный
  ход. Застрять нельзя: на каждом шаге есть «ДАЛЬШЕ», а в шапке — «ПРОПУСТИТЬ».
- Обучение **не блокирует игру**: свайпы, крестовина и кнопки работают как обычно, карточка
  не перекрывает нижнюю зону управления и скрывается под оверлеями перков/победы/справки.
- Прогресс хранится отдельно от партии в `localStorage` (`edge-push:tutorial:v1`), поэтому
  autosave игры не затирается. Повторить обучение можно в любой момент: `?` → **«Повторить
  обучение»**. Новый забег (`↺`) обучение заново не показывает.

## Цветовой контракт

**Один цвет = одна роль.** Это не украшение, а словарь: защищённые оттенки запрещено
использовать как декор, иначе игрок перестаёт с первого взгляда понимать, кто за кого.

| Роль | Переменная | Цвет | Что красит |
| --- | --- | --- | --- |
| СВОЙ | `--ally` | `#00e5ff` бирюзовый | герой, щит, сердца HP, бренд, активный режим, кнопки и оверлеи игрока |
| ЧУЖОЙ | `--hostile` | `#ff4757` красный | **все пять архетипов врагов**, урон, телеграфы намерений, поражение |
| ОБЪЕКТ / ВНИМАНИЕ | `--neutral` | `#ffb037` янтарный | бочки, цифры отката, `⚡`, подсказки и всплывающие тексты |
| ОПАСНАЯ МЕСТНОСТЬ | `--hazard` | `#ff7a1a` оранжевый | лава и шипы — всегда вместе со штриховкой |
| БЕЗОПАСНЫЙ ХОД | `--safe` | `#5cffb0` мятно-зелёный | превью шага, крюка, броска и валидные направления крестовины |
| ИНЕРТНОЕ | `--tile`, `--void` | сланец / чёрный | пол, колонна, пропасть, фон, приглушённые «спящие» враги |

Оттенок **не различает врагов**: все они красные, а тип задаётся **формой** (квадрат, ромб,
треугольник, круг, квадрат в двойной рамке) и подписью в легенде. Так «кто за кого» читается
мгновенно: любая красная фигура — чужой, любая бирюзовая — свой, любая зелёная рамка — ваш
безопасный ход, любая оранжевая штриховка — опасная клетка, а не юнит.

**Рецепт, по которому это собрано:**

1. **Принадлежность по NATO APP-6** — синий/бирюзовый = свой, красный = чужой, зелёный =
   нейтральный, жёлтый = неизвестный; рамка-форма дублирует цвет ([Wikipedia](https://en.wikipedia.org/wiki/NATO_Joint_Military_Symbology)).
   Отсюда же «один цвет стороны на все типы юнитов», а не радуга архетипов.
2. **Игровая color language** — красный = опасность, жёлтый/янтарный = интерактивный объект,
   зелёный = безопасное/разрешённое действие, cyan = маркер игрока; активные оттенки
   **защищены** и не используются в фоне ([color script / protected hues](https://nastyrodent.com/color-theory-for-game-art/),
   [game UI color guide](https://generalistprogrammer.com/tutorials/game-ui-design-complete-interface-guide-2025)).
3. **WCAG 2.2 1.4.1 «Use of Color»** — цвет никогда не бывает единственным каналом: к нему
   всегда добавлены форма, паттерн, иконка или текст ([MDN](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Understanding_WCAG/Perceivable/Use_of_color),
   [W3C-разбор](https://www.thewcag.com/criteria/1-4-1)). Поэтому шипы со штриховкой, `!` на бочке,
   `⚡`, `Z`, белые точки HP и подписанная легенда обязательны.
4. **Дальтонизм** — вместо чистой красно-зелёной пары взяты reddish `#ff4757` и
   bluish-green `#5cffb0`, которые различимы при дейтеранопии (рекомендация того же MDN).
5. **Телеграфы в духе Into the Breach**: красные полосы/рамки = imminent attack, зелёные
   клетки = доступные ходы ([разбор визуального языка ITB](https://skullduggery.us/rants/into-the-breach/)).

Контракт объявлен один раз в `:root` (`COLOR CONTRACT`), старые алиасы `--cyan`, `--red`,
`--amber` ссылаются на него, а JS-объект `PAL` синхронизирован с CSS. Это проверяется тестом:
нельзя случайно вернуть «фиолетового снайпера» или «оранжевого быка». Красный `--hostile`
используется и для отказа «НЕТ ПУТИ»: это тоже «нельзя», а не нейтральная подсказка.

## Легенда обозначений

В игре нет спрайтов: **цвет говорит за какую сторону, форма — кто именно**. Полноцветная
мини-легенда с настоящими иконками и разделом «Палитра» открывается кнопкой `▦` в верхней
панели, из справки `?`, кнопкой «ЛЕГЕНДА» в обучении или клавишей `L`.

| Что видите | Кто это | Что делает |
| --- | --- | --- |
| Бирюзовый скруглённый квадрат с ромбом | **Герой** | 3 ♥ (сердца тоже бирюзовые), шаг или толчок; кольцо = щит |
| Красный квадрат | **Громила** (`BRUTE`) | 2 ♥, бьёт вплотную и толкает на 1 клетку |
| Красный ромб | **Бык** (`CHARGER`) | 2 ♥, несётся по линии на 4 клетки, может улететь сам |
| Красный треугольник | **Снайпер** (`SNIPER`) | 1 ♥, стреляет первым объектом на линии, в том числе своим |
| Красный круг с фитилём | **Бомбер** (`BOMBER`) | 1 ♥, идёт к герою, взрывается от любого урона |
| Тёмно-красный квадрат в двойной рамке | **Джаггернаут** (`JUGGERNAUT`) | 4 ♥ на 7 этаже, сдвигается только на 1 клетку |
| Янтарная бочка с `!` | **Бочка** (`BARREL`) | взрыв 3×3 от любого урона: 2 урона + разлёт |
| Серая плита со скошенной гранью | **Пол** | сюда можно шагнуть |
| Пустая клетка с пунктирным краем | **Пропасть** | мгновенная смерть для любого юнита |
| Светлый каменный блок с штриховкой | **Колонна** | непроходима, удар о неё = 1 урон |
| Оранжевая штриховка с `▲` / языки пламени на шлаке | **Шипы / Лава** | 1 урон толкнутому юниту |
| `⚡` янтарная над врагом | Активная угроза | действует в этот ход, таких не больше двух |
| `Z` над врагом | Оглушён | теряет намерение и пропускает ход |
| Белые точки под врагом | Очки HP | сколько ударов он ещё выдержит |
| Красная стрелка / рамка / луч | Намерение | телеграф атаки активного врага |
| Зелёная рамка, точка или луч | Превью | куда шагнёте вы или прилетит цель крюка/броска |
| Янтарная цифра на кнопке приёма | Откат | сколько ходов осталось ждать |
| `ЩИТ ×N` вверху | Щит | гасит один удар или толчок |

Неактивные враги приглушены (`opacity .72`) и без `⚡` — в фазу врагов они не двигаются.

**Отказ в ходе:** шаг в пропасть, лаву, шипы или колонну не тратит ход. В ответ на поле
появляется крупный баннер `НЕТ ПУТИ / ХОД НЕ ПОТРАЧЕН`, красный крест на заблокированной
клетке, мигают недоступные направления крестовины, а сверху всплывает красный тост — плюс
короткая тряска и вибрация. Мелкого текста над клеткой больше нет.

## Масштабируемый интерфейс

Вся геометрия привязана к одной величине `--u`, а не к набору магических пикселей:

```css
--u:      clamp(9px, min(2.7vw, 1.4dvh), 14px);       /* базовый шаг */
--chrome: clamp(82px, 12.2dvh, 108px);                  /* HUD + подсказка + зазоры */
--board:  min(92vw, 46dvh, calc(55dvh - var(--chrome)), 440px);
--btn:    clamp(56px, min(17.5vw, 8.2dvh), 84px);     /* кнопки крестовины */
```

Шрифты, отступы, радиусы, иконки, оверлеи, легенда, обучение и тост — всё считается как
`calc(var(--u) * k)`. Сохраняется каркас ТЗ: `100dvh`, `touch-action:none`, верх 55% /
низ 45%, поле `min(92vw, 46dvh)`, без скролла. Поле дополнительно ограничено свободной высотой
верхней зоны, поэтому HUD и подсказка никогда не вылезают в зону управления.

Проверено в headless Chromium на **320×568, 360×640, 375×667, 390×844, 412×915,
430×932, 480×800**: `scrollHeight === clientHeight`, HUD не обрезает кнопки `▦ ? ↺`,
«Понятно» в легенде всегда в пределах экрана, карточка обучения не перекрывает кнопки.
На телефонах от ~390 px кнопки D-pad остаются ≥64 px по ТЗ; на совсем маленьких
(320×568, 360×640) они честно уменьшаются до 56 px, но всё ещё крупнее минимального
тач-таргета 44 px — иначе 45% высоты физически не вмещают три ряда кнопок. На экранах
≤520 px по высоте (старые телефоны, альбомная ориентация) включается дополнительный
режим: `--u` уходит к 7 px, второстепенные подписи прячутся, а в альбоме показывается
«поверните телефон вертикально». Проверены также 320×480, 740×360 и 844×390.

## Эволюционный ИИ и проходимость игры

Отдельный инструмент анализа в `ai/`. **Игра не изменена**: ИИ запускает тот же
детерминированный движок из `index.html` по маркерам `ENGINE START/END`, без DOM,
без внешних библиотек и без копий правил.

```bash
npm run ai          # эволюция → проверка → ai/index.html
npm run ai:evolve   # только обучение (по умолчанию ~5–6 минут)
npm run ai:evaluate # только проверка на новых сидах (~2 минуты)
npm run ai:report   # пересобрать HTML-отчёт из сохранённых JSON
npm run test:ai     # 9 быстрых тестов ИИ
```

Откройте **`ai/index.html`** (в превью — `/ai/index.html`, или просто `file://`): там
графики обучения, сравнение политик, вердикт и пошаговый реплей выигрышной партии
с кнопками воспроизведения. Данные встроены в HTML, сеть не нужна.

### Как он учится

Геном — **34 веса**: 28 признаков линейной функции ценности действия
`Q(s,a) = w · φ(s,a)` и 6 весов выбора перков. На каждом ходу ИИ перебирает все
легальные действия (4 направления × 3 режима, `ЖДАТЬ`, выбор перка), **честно
проигрывает каждое полным ходом движка** (включая фазу врагов и перезарядки) и
выбирает максимум `Q`. Признаки — убийства, сбросы в бездну, HP, число врагов,
прицелы по герою, близость к краю, готовность крюка/броска и т.п.

Веса подбирает **генетический алгоритм**: турнирный отбор, элитизм 4, смешанное
скрещивание, гауссова мутация с убыванием σ от 0.55 до 0.07, 2 иммигранта на
поколение. Никаких учителей, градиентов, A*, MCTS и подсмотренных стратегий в
самой политике — только приспособленность целых партий (1200 за этаж, 6000 за
победу, бонусы за убийства и живое HP, штрафы за гибель и затягивание).

Чтобы не заучить конкретные расклады, обучающие сиды **ротируются** (пул 32,
по 8 на поколение), чемпион отбирается по отдельным 16 калибровочным сидам,
а итоговая проверка идёт на третьей, полностью невидимой выборке
**100 сидов 1001–1100**.

### Результат: игра проходима

| Политика / поиск | Побед из 100 | Ср. этажей | Ср. убийств | Ср. фитнес |
| --- | --- | --- | --- | --- |
| Случайные ходы | 0 | 0.15 | 1.95 | 126 |
| Поколение 0 (до обучения) | 0 | 0.45 | 2.91 | 514 |
| Жадная эвристика | 1 | 0.75 | 4.04 | 924 |
| **Эволюционировавший ИИ** | **6** | **2.38** | **10.34** | **3612** |
| Стохастический поиск по его оценкам (12 попыток) | 37 | — | — | — |
| Поиск лучом W=96, направляемый им же | 90 | 6.73 | — | — |
| **Объединённо найдена выигрышная линия** | **93** | — | — | — |

За 60 поколений рекорд на калибровке вырос **1409 → 6592 (+368%)**, среднее по
популяции **28 → 9183**, средняя глубина забега **1.06 → 2.75/7**. Чемпион
выигрывает 6 партий из 100 с первой попытки — в реплее его победа на сиде 1023
за 43 хода, все 7 этажей. Поиск (это уже не обучение, а вопрос «существует ли
выигрышная последовательность») находит конкретные траектории для **93 из 100**
сидов. Игра детерминирована, сид задаёт все 7 этажей, поэтому воспроизведённый
реплей — конструктивное доказательство проходимости.

**Честно об ограничениях:** для 7 сидов 12 стохастических попыток и луч шириной
96 не нашли победы. Это ограничение бюджета поиска, **не** доказательство
непроходимости сида. Вывод «проходима» относится к 100 проверенным сидам, а не
ко всем возможным и не к «человеку легко пройдёт».

## Правила

- **1 ход = 1 действие.** Время идёт только в момент хода, таймеров нет. Состояние пишется в
  `localStorage` (`edge-push:v1`) после каждого действия, смены режима, выбора перка и рестарта;
  при перезагрузке партия восстанавливается автоматически.
- **Базовый шаг:** пустая клетка → шаг; враг или бочка → толчок на 2 клетки (3+ с перком);
  пропасть / лава / шипы / колонна / край → ход **не тратится**, короткий шейк (защита от
  случайной смерти).
- **Импульс `resolvePush`:** вылет за край или в `CHASM` → мгновенная смерть; `PILLAR` → 1 урон
  («Шипованные стены»: 2 врагу); столкновение с другим юнитом → **оба** получают 1 урон и
  импульс передаётся дальше на 1 клетку (домино); `LAVA`/`SPIKES` → 1 урон и остановка.
  После всех сдвигов бочки и бомберы с уроном взрываются **очередью**: 2 урона в квадрате 3×3
  и разлёт соседей на 1 клетку от эпицентра — работают цепные детонации.
- **Крюк:** луч на дистанции 2–4 по одной из 4 осей, первая цель притягивается на клетку прямо
  перед героем. Если там пропасть — цель падает, если ловушка — получает урон. Луч блокируется
  колонной. Откат 2 хода.
- **Бросок:** цель перед героем перелетает за спину; позади свободный пол / пропасть / лава /
  шипы — летит (край карты = бездна). Позади колонна или юнит → **смена мест** и оглушение
  (активное намерение `⚡` теряется). Откат 2 хода.
- **Угрозы:** в начале хода выбирается не более **2** живых врагов по очереди спавна. Только они
  получают `⚡` и пульсирующее красное намерение; остальные приглушены и в фазу врагов бездействуют.
  Убитый/оглушённый активный враг просто пропускает ход — внезапной замены не бывает.
- **Архетипы:** `BRUTE` (2 HP, шаг/удар вплотную с толчком), `CHARGER` (2 HP, фиксирует линию и
  несётся на 4 клетки — уйдите вбок, и он улетит сам), `SNIPER` (1 HP, бьёт первый объект на
  линии, в том числе своего), `BOMBER` (1 HP, идёт к герою, взрывается от любого урона),
  `JUGGERNAUT` (4 HP на 7 этаже, сдвигается только на 1 клетку, но падает смертельно).
- **Забег:** 7 этажей; этаж пройден мгновенно, когда врагов не осталось. В конце этажа откаты
  сбрасываются, щит обнуляется, игрок берёт **1 из 3** случайных перков; на 7-м — победа.
  HP и перки переносятся между этажами. Щит от «Ждать» гасит **один удар или один толчок**.
- **Генерация:** центр 3×3 преимущественно `FLOOR`, на внешнем кольце 6–10 пропастей, 1–2
  колонны, 1–2 ловушки, 1–2 бочки. Герой у центра, враги на свободном полу на расстоянии ≥ 2.
  Проверяется связность всех проходимых клеток, ≥ 2 выхода у героя и ≥ 2 «ворот» в бездну —
  арен без тупиков и изолированных островков не бывает (при неудаче 300 попыток есть
  заведомо связный fallback).

### Перки

| Перк | Эффект |
| --- | --- |
| Тяжёлый таран | толчок на 3+ клетки |
| Шипованные стены | удар врага о колонну: 2+ урона |
| Азартный гарпун | крюк, сразу убивший цель, перезаряжается |
| Ударное приземление | после броска соседние враги отлетают от героя |
| Длинные цепи | откат крюка и броска 1 ход (дальше — 0) |
| Второе дыхание | +1 макс. HP и полное лечение |

Перки стакаются (уровень показывает результат), карточки всегда три разные.

## Архитектура

```
index.html
 ├─ <style>              портретная верстка 55/45, 100dvh, touch-action:none, «сочность»
 ├─ <script id="engine-script">   ЧИСТЫЙ детерминированный конечный автомат
 │    между маркерами /* ===== ENGINE START/END ===== */
 │    grid[5][5], целые координаты, LCG-RNG в state, никаких DOM/timer/физики/A*
 │    EdgeEngine: createGame / performTurn / setMode / choosePerk / preview / ...
 │    performTurn → { state, frames:[{state, events}] } для покадровой анимации
 └─ <script id="ui-script">       рендер DOM/SVG, FX, ввод, localStorage, оверлеи,
                                 FSM обучения (6 шагов), легенда «кто есть кто»
ai/                            НЕ часть игры: эволюционный ИИ и анализ проходимости
 ├─ engine.mjs                  загрузка того же движка по маркерам в node:vm
 ├─ policy.mjs                  34 гена, признаки, Q(s,a), прогон партии
 ├─ evolve.mjs                  генетический алгоритм → ai/training.json
 ├─ oracle.mjs                  поиск лучом → верхняя оценка проходимости
 ├─ evaluate.mjs                проверка на невидимых сидах → ai/results.json
 ├─ report.mjs                  самодостаточный отчёт ai/index.html
 └─ replay.json / *.json        чемпион, история, результаты, реплей
```

Состояние — плоский JSON (включая `rng`), поэтому автосохранение и тесты тривиальны.
Флаг пройденного обучения лежит в отдельном ключе и в состояние партии не входит.
Скольжение юнитов — CSS `transform: translate(x*100%, y*100%)` + `transition 145ms ease-out`;
смерти, взрывы, всплывающие `ВЗРЫВ -2` / `ПРОПАСТЬ!` / `ДУПЛЕТ!`, шейк и вибрация приходят из
`events` кадра. Намерения и превью рисуются в одном inline-SVG с `viewBox="0 0 100 100"`.

## Осознанные трактовки ТЗ

- В ТЗ одновременно сказано «ловушка наносит 1 урон при входе» и «базовый шаг в
  `LAVA`/`SPIKES` блокируется». Приоритет отдан защите игрока: **шаг** героя на опасную клетку
  запрещён, урон от ловушки получают только **толкнутые/притянутые/брошенные** юниты.
- `JUGGERNAUT` заменяет одного из 5 врагов 7-го этажа, чтобы сохранить лимит «3–5 врагов» и
  читаемость поля; это один из пяти, а не шестой.
- Крюк не работает в направлении, где вплотную стоит `PILLAR` (луч не проходит сквозь камень),
  и игнорирует юнита на `i=1` («вплотную крюк не нужен»). Если клетка перед героем занята,
  притянутая цель и тот юнит получают по 1 урона столкновения, цель остаётся на месте.
- Разлёт от взрыва и «Ударное приземление» для диагональных соседей выбирают **преобладающую
  ось** (движение строго осевое, как в ТЗ). Брошенная цель не участвует в собственном разлёте.
- Щит считается одной зарядкой на **один impact**: гасит урон и/или толчок одного удара,
  взрыва или столкновения, после чего сгорает; не израсходованный щит обнуляется в начале
  следующего хода игрока.
- Иконки кнопок и перков нарисованы inline-SVG, а не эмодзи: геометрический стиль ТЗ
  сохраняется и не зависит от наличия emoji-шрифта на устройстве.
- `CHASM` внутри поля и вылет за границу равнозначны и мгновенно смертельны; падение бочки в
  бездну не взрывает её, а гибель `BOMBER` взрывает на последней клетке перед падением.

## Стек и совместимость

HTML5 / ES2020 / CSS Grid / inline SVG / `localStorage` / `navigator.vibrate` (опционально).
Проверено в jsdom и в headless Chromium (портрет 390×844, режим крюка, оверлей перков,
десктопное окно) и рассчитано на современные мобильные Safari/Chrome: `100dvh`,
`viewport-fit=cover`, `env(safe-area-inset-bottom)`, `aspect-ratio`, `touch-action: none`.
На десктопе приложение центрируется колонкой шириной ≤ 480px, сохраняя портретную эргономику.
