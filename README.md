# КРАЙ / Edge Push

Пошаговая микро-тактика **непрямого боя** для одной руки в портретном мобильном браузере.
Каменный остров 5×5, 7 этажей, 2–3 минуты на забег. Прямых ударов нет: враги гибнут от
**толчков в пропасть, лаву, колонны, взрывные бочки и друг в друга**.

**Один файл `index.html` — вся игра.** Vanilla JS + DOM/CSS/SVG, без сборки, без библиотек,
без внешних ассетов, без сети. Работает даже по `file://` (просто откройте файл в браузере).

```bash
npm start          # python3 -m http.server 8000 → http://localhost:8000
npm test           # 45 автоматических тестов (движок + UI + обучение + легенда)
```

## Управление

| Действие | Как |
| --- | --- |
| Шаг / толчок щитом | Крестовина `▲ ▼ ◄ ►` **или свайп в любой точке экрана** (порог 30 px) |
| Крюк | Тап по кнопке (режим-переключатель), затем направление. Повторный тап отменяет |
| Бросок через плечо | Тап по кнопке, затем направление на врага/бочку перед героем |
| Ждать | Пропустить ход, получить +1 щит до начала следующего хода игрока |
| ▦ / ? | Легенда «кто есть кто» / правила (в справке — повтор обучения) |
| ↺ | Новый забег (с подтверждением) |
| Клавиатура | `←↑→↓` или `WASD`, `1` — крюк, `2` — бросок, `3`/`Space` — ждать, `L` — легенда, `R` — заново |

Нажимать на клетки поля **не нужно и нельзя**: весь ввод живёт в нижней эргономичной зоне,
поэтому тряска в транспорте не приводит к миссклику. Верхние 55% экрана — поле и статы,
нижние 45% — D-pad (кнопки ≥ 64 px) и три крупные кнопки приёмов с крупной цифрой отката.

## Обучение при первом запуске

При первом открытии игры поверх нижней части поля появляется компактная карточка с
**6 шагами**: цель, ход одной рукой, толчок, лимит `⚡` и телеграфы, три приёма, структура забега.
Нужные элементы пульсируют: крестовина, три кнопки приёмов или само поле.

- Шаги 2 и 3 — **интерактивные**: они завершаются автоматически, когда игрок делает реальный
  ход. Застрять нельзя: на каждом шаге есть «ДАЛЬШЕ», а в шапке — «ПРОПУСТИТЬ».
- Обучение **не блокирует игру**: свайпы, крестовина и кнопки работают как обычно, карточка
  не перекрывает нижнюю зону управления и скрывается под оверлеями перков/победы/справки.
- Прогресс хранится отдельно от партии в `localStorage` (`edge-push:tutorial:v1`), поэтому
  autosave игры не затирается. Повторить обучение можно в любой момент: `?` → **«Повторить
  обучение»**. Новый забег (`↺`) обучение заново не показывает.

## Легенда обозначений

В игре нет спрайтов: **форма + цвет** говорят, кто перед вами. Полноцветная мини-легенда
с настоящими иконками открывается кнопкой `▦` в верхней панели, из справки `?`, кнопкой
«ЛЕГЕНДА» в обучении или клавишей `L`.

| Что видите | Кто это | Что делает |
| --- | --- | --- |
| Бирюзовый скруглённый квадрат с ромбом | **Герой** | 3 ♥, шаг или толчок; бирюзовое кольцо = щит |
| Красный квадрат | **Громила** (`BRUTE`) | 2 ♥, бьёт вплотную и толкает на 1 клетку |
| Оранжевый ромб | **Бык** (`CHARGER`) | 2 ♥, несётся по линии на 4 клетки, может улететь сам |
| Фиолетовый треугольник | **Снайпер** (`SNIPER`) | 1 ♥, стреляет первым объектом на линии, в том числе своим |
| Жёлтый круг с фитилём | **Бомбер** (`BOMBER`) | 1 ♥, идёт к герою, взрывается от любого урона |
| Тёмно-красный квадрат в двойной рамке | **Джаггернаут** (`JUGGERNAUT`) | 4 ♥ на 7 этаже, сдвигается только на 1 клетку |
| Коричневая бочка с `!` | **Бочка** (`BARREL`) | взрыв 3×3 от любого урона: 2 урона + разлёт |
| Серая плита со скошенной гранью | **Пол** | сюда можно шагнуть |
| Пустая клетка с пунктирным краем | **Пропасть** | мгновенная смерть для любого юнита |
| Светлый каменный блок с штриховкой | **Колонна** | непроходима, удар о неё = 1 урон |
| Красная штриховка с `▲` / оранжевое свечение | **Шипы / Лава** | 1 урон толкнутому юниту |
| `⚡` над врагом | Активная угроза | действует в этот ход, таких не больше двух |
| `Z` над врагом | Оглушён | теряет намерение и пропускает ход |
| Белые точки под врагом | Очки HP | сколько ударов он ещё выдержит |
| Красная стрелка / рамка / луч | Намерение | телеграф атаки активного врага |
| Бирюзовая рамка, точка или луч | Превью | куда шагнёте вы или прилетит цель крюка/броска |
| Цифра на кнопке приёма | Откат | сколько ходов осталось ждать |
| `ЩИТ ×N` вверху | Щит | гасит один удар или толчок |

Неактивные враги приглушены (`opacity .72`) и без `⚡` — в фазу врагов они не двигаются.

## Правила

- **1 ход = 1 действие.** Время идёт только в момент хода, таймеров нет. Состояние пишется в
  `localStorage` (`edge-push:v1`) после каждого действия, смены режима, выбора перка и рестарта;
  при перезагрузке партия восстанавливается автоматически.
- **Базовый шаг:** пустая клетка → шаг; враг или бочка → толчок на 2 клетки (3+ с перком);
  пропасть / лава / шипы / колонна / край → ход **не тратится**, короткий шейк (защита от
  случайной смерти).
- **Импульс `resolvePush`:** вылет за край или в `CHASM` → мгновенная смерть; `PILLAR` → 1 урон
  («Шипованные стены»: 2 врагу); столкновение с другим юнитом → **оба** получают 1 урон и
  импульс передаётся дальше на 1 клетку (домино); `LAVA`/`SPIKES` → 1 урон и остановка.
  После всех сдвигов бочки и бомберы с уроном взрываются **очередью**: 2 урона в квадрате 3×3
  и разлёт соседей на 1 клетку от эпицентра — работают цепные детонации.
- **Крюк:** луч на дистанции 2–4 по одной из 4 осей, первая цель притягивается на клетку прямо
  перед героем. Если там пропасть — цель падает, если ловушка — получает урон. Луч блокируется
  колонной. Откат 2 хода.
- **Бросок:** цель перед героем перелетает за спину; позади свободный пол / пропасть / лава /
  шипы — летит (край карты = бездна). Позади колонна или юнит → **смена мест** и оглушение
  (активное намерение `⚡` теряется). Откат 2 хода.
- **Угрозы:** в начале хода выбирается не более **2** живых врагов по очереди спавна. Только они
  получают `⚡` и пульсирующее красное намерение; остальные приглушены и в фазу врагов бездействуют.
  Убитый/оглушённый активный враг просто пропускает ход — внезапной замены не бывает.
- **Архетипы:** `BRUTE` (2 HP, шаг/удар вплотную с толчком), `CHARGER` (2 HP, фиксирует линию и
  несётся на 4 клетки — уйдите вбок, и он улетит сам), `SNIPER` (1 HP, бьёт первый объект на
  линии, в том числе своего), `BOMBER` (1 HP, идёт к герою, взрывается от любого урона),
  `JUGGERNAUT` (4 HP на 7 этаже, сдвигается только на 1 клетку, но падает смертельно).
- **Забег:** 7 этажей; этаж пройден мгновенно, когда врагов не осталось. В конце этажа откаты
  сбрасываются, щит обнуляется, игрок берёт **1 из 3** случайных перков; на 7-м — победа.
  HP и перки переносятся между этажами. Щит от «Ждать» гасит **один удар или один толчок**.
- **Генерация:** центр 3×3 преимущественно `FLOOR`, на внешнем кольце 6–10 пропастей, 1–2
  колонны, 1–2 ловушки, 1–2 бочки. Герой у центра, враги на свободном полу на расстоянии ≥ 2.
  Проверяется связность всех проходимых клеток, ≥ 2 выхода у героя и ≥ 2 «ворот» в бездну —
  арен без тупиков и изолированных островков не бывает (при неудаче 300 попыток есть
  заведомо связный fallback).

### Перки

| Перк | Эффект |
| --- | --- |
| Тяжёлый таран | толчок на 3+ клетки |
| Шипованные стены | удар врага о колонну: 2+ урона |
| Азартный гарпун | крюк, сразу убивший цель, перезаряжается |
| Ударное приземление | после броска соседние враги отлетают от героя |
| Длинные цепи | откат крюка и броска 1 ход (дальше — 0) |
| Второе дыхание | +1 макс. HP и полное лечение |

Перки стакаются (уровень показывает результат), карточки всегда три разные.

## Архитектура

```
index.html
 ├─ <style>              портретная верстка 55/45, 100dvh, touch-action:none, «сочность»
 ├─ <script id="engine-script">   ЧИСТЫЙ детерминированный конечный автомат
 │    между маркерами /* ===== ENGINE START/END ===== */
 │    grid[5][5], целые координаты, LCG-RNG в state, никаких DOM/timer/физики/A*
 │    EdgeEngine: createGame / performTurn / setMode / choosePerk / preview / ...
 │    performTurn → { state, frames:[{state, events}] } для покадровой анимации
 └─ <script id="ui-script">       рендер DOM/SVG, FX, ввод, localStorage, оверлеи,
                                 FSM обучения (6 шагов), легенда «кто есть кто»
```

Состояние — плоский JSON (включая `rng`), поэтому автосохранение и тесты тривиальны.
Флаг пройденного обучения лежит в отдельном ключе и в состояние партии не входит.
Скольжение юнитов — CSS `transform: translate(x*100%, y*100%)` + `transition 145ms ease-out`;
смерти, взрывы, всплывающие `ВЗРЫВ -2` / `ПРОПАСТЬ!` / `ДУПЛЕТ!`, шейк и вибрация приходят из
`events` кадра. Намерения и превью рисуются в одном inline-SVG с `viewBox="0 0 100 100"`.

### Тесты

```bash
npm install          # только dev-зависимость: jsdom для UI smoke-тестов
npm test             # node --test tests/*.test.mjs
npm run test:engine  # 32 теста: генерация (200 сидов), импульс/домино, цепные взрывы,
                     #            крюк/бросок, щит, ИИ архетипов, откаты, 7 этажей,
                     #            детерминизм, JSON-сохранение, фазз 30×250 ходов
npm run test:ui      # 13 тестов: реальный запуск index.html в jsdom, тапы, свайпы,
                     #            клавиатура, оверлей перков/победы/поражения, рестарт,
                     #            6 шагов обучения, пропуск/повтор, игра поверх карточки,
                     #            легенда (7 юнитов / 5 клеток / 6 меток) и все входы в неё
```

Движок вытаскивается из `index.html` по маркерам и исполняется в `node:vm` — дублирования
кода нет. `jsdom` нужен только тестам, сама игра зависимостей не имеет.

## Осознанные трактовки ТЗ

- В ТЗ одновременно сказано «ловушка наносит 1 урон при входе» и «базовый шаг в
  `LAVA`/`SPIKES` блокируется». Приоритет отдан защите игрока: **шаг** героя на опасную клетку
  запрещён, урон от ловушки получают только **толкнутые/притянутые/брошенные** юниты.
- `JUGGERNAUT` заменяет одного из 5 врагов 7-го этажа, чтобы сохранить лимит «3–5 врагов» и
  читаемость поля; это один из пяти, а не шестой.
- Крюк не работает в направлении, где вплотную стоит `PILLAR` (луч не проходит сквозь камень),
  и игнорирует юнита на `i=1` («вплотную крюк не нужен»). Если клетка перед героем занята,
  притянутая цель и тот юнит получают по 1 урона столкновения, цель остаётся на месте.
- Разлёт от взрыва и «Ударное приземление» для диагональных соседей выбирают **преобладающую
  ось** (движение строго осевое, как в ТЗ). Брошенная цель не участвует в собственном разлёте.
- Щит считается одной зарядкой на **один impact**: гасит урон и/или толчок одного удара,
  взрыва или столкновения, после чего сгорает; не израсходованный щит обнуляется в начале
  следующего хода игрока.
- Иконки кнопок и перков нарисованы inline-SVG, а не эмодзи: геометрический стиль ТЗ
  сохраняется и не зависит от наличия emoji-шрифта на устройстве.
- `CHASM` внутри поля и вылет за границу равнозначны и мгновенно смертельны; падение бочки в
  бездну не взрывает её, а гибель `BOMBER` взрывает на последней клетке перед падением.

## Стек и совместимость

HTML5 / ES2020 / CSS Grid / inline SVG / `localStorage` / `navigator.vibrate` (опционально).
Проверено в jsdom и в headless Chromium (портрет 390×844, режим крюка, оверлей перков,
десктопное окно) и рассчитано на современные мобильные Safari/Chrome: `100dvh`,
`viewport-fit=cover`, `env(safe-area-inset-bottom)`, `aspect-ratio`, `touch-action: none`.
На десктопе приложение центрируется колонкой шириной ≤ 480px, сохраняя портретную эргономику.
