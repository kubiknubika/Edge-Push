# Google Play · листинг (RU)

Готовые тексты для Play Console. Копируйте без заголовков разделов; lengths указаны для справки.

## Название (≤30)

`КРАЙ · Edge Push`

## Краткое описание (≤80)

`Пошаговая микро-тактика: толкай врагов в пропасть, лаву и шипы.`

## Полное описание (≤4000)

```
КРАЙ — пошаговая микро-тактика непрямого боя для одной руки. Прямых атак нет:
вы толкаете врагов в пропасть, лаву, шипы, бочки, колонны и друг в друга.

СЕМЬ ЭТАЖЕЙ. На каждом — поле 5×5, 3–5 противников и не больше двух активных
угроз одновременно. После этажей 1–6 выбираете один из трёх перков. Победа —
дойти до конца, сохранив хотя бы одно из трёх сердец.

ДЕСЯТЬ УРОВНЕЙ СЛОЖНОСТИ. От «ПРОГУЛКИ» до «КРАЯ». Уровень меняет только пул
сидов, подобранный по измеренной сложности: HP, число врагов, правила толчка,
перки и угрозы одинаковы на всех уровнях.

УПРАВЛЕНИЕ. Крестовина в нижней половине экрана или свайп на 30px в любом месте.
Три крупные кнопки способностей с крупными цифрами отката: крюк, бросок, ожидание
со щитом. Нажатия по клеткам поля отключены — случайный тап не испортит ход.

ПОНЯТНО С ПЕРВОГО ЗАПУСКА. Шестишаговое обучение, легенда «КТО ЕСТЬ КТО» с
настоящими мини-иконками и единый цветовой контракт: cyan — свой, красный —
чужой/запрет, amber — объект, оранжевый с паттерном — опасная местность,
bluish-green — безопасный ход. Цвет никогда не единственный канал: формы,
подписи и штриховка дублируют смысл (WCAG 1.4.1).

АВТОСОХРАНЕНИЕ после каждого хода. Закрыли игру — вернулись в ту же партию.
Тёмный неоновый портретный интерфейс, масштабируется под маленькие телефоны,
100dvh без прокрутки.

ОФЛАЙН. Никакой сети, аккаунта, аналитики, рекламы и покупок. Прогресс лежит
только в localStorage на устройстве. Разрешение INTERNET не запрашивается:
единственное разрешение — VIBRATE для короткой вибрации.

Это не «лёгкая» игра: эволюционный ИИ без поиска выигрывает лишь 18/100 партий,
а 100% прохождение достигается детерминированным планировщиком на исправленном
генераторе, который исключает непроходимые раскладки.
```

## Что нового (≤500)

```
Первый релиз 1.0.0: 7 этажей, 10 уровней сложности с отобранными сидами,
обучение, легенда, автосохранение, офлайн-PWA и нативная Android-обёртка.
Генератор проверяет каждый этаж на проходимость.
```

## Категория и теги

- Категория: **Игры → Головоломки** (альтернатива: Стратегии).
- Теги: пошаговая, тактика, пазл, офлайн, без рекламы, одна рука, портрет, русский.
