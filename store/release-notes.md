# КРАЙ / Edge Push · release notes

## 1.0.0 · 3 ноября 2026

Первый публичный релиз.

- 7 этажей, поле 5×5, 3–5 врагов, не больше 2 активных угроз, 3 сердца, перки после этажей 1–6.
- Победа толчком в пропасть / лаву / шипы / бочки / колонны / других врагов; прямых атак нет.
- 10 уровней сложности: каждый уровень использует свой пул из 12 сидов, отобранных по измеренной сложности. Механика не меняется.
- Генератор проверяет проходимость каждой раскладки и перегенерирует тупики (исправление сида 4095).
- Обучение при первом запуске, легенда «КТО ЕСТЬ КТО», единый цветовой контракт и заметный отказ «НЕТ ПУТИ».
- Автосохранение после каждого хода, портретный `100dvh` без скролла, крестовина и свайп 30px, крупные кнопки способностей.
- Офлайн: installable PWA (manifest + service worker + maskable-иконки) и нативная Android-обёртка с локальными ассетами.
- Нет сети, аккаунта, аналитики, рекламы, покупок и сторонних рантайм-SDK; единственное разрешение — `VIBRATE`.
- Исследовательский отчёт эволюционного ИИ: 200/200 уверенных побед на двух непересекающихся наборах сидов, честное разделение «обученная политика vs детерминированный поиск».
- Тесты: 124/124 (72 игровых/ИИ + 52 релизных); gate `npm run release:check` — 51/51.

### Известное

На очень маленьких и низких экранах D-pad может быть меньше 64px, чтобы сохранить 45% высоты под управление без прокрутки. Компромисс описан в `README.md`.
