# Google Play · Data safety

Ответы для формы «Безопасность данных». Копируйте как есть; при изменении приложения перепроверьте.

| Пункт формы | Ответ |
| --- | --- |
| Собирает ли приложение данные? | **Нет.** |
| Передаёт ли данные третьим лицам? | **Нет.** |
| Типы данных | Не применимо: имя, e-mail, ID устройства, геолокация, контакты, фото/видео/файлы, история покупок, диагностика и использование не собираются. |
| Цель сбора | Не применимо. |
| Данные в покое | Прогресс партии хранится только в приватном `localStorage` приложения; шифруется стандартным шифрованием устройства, если оно включено. Не покидает устройство. |
| Данные в transit | Исходящего трафика нет. Разрешение `INTERNET` отсутствует. |
| Шифрование при передаче | Не применимо. |
| Сторонние SDK | Нет. Нативная обёртка использует только `androidx.webkit:webkit` (загрузка локальных ассетов), в игре — vanilla JS/DOM без библиотек. |
| Рекламные идентификаторы | Не используются. |
| Аналитика / краш-репорты в приложении | Нет. (Сводки Play Console — инфраструктура магазина, не код приложения.) |
| Удаление данных | Удаление приложения или «Очистить данные» в настройках Android. Аккаунта и серверной копии нет. |
| Резервное копирование | Отключено: `android:allowBackup="false"` + `data_extraction_rules.xml`. |
| Политика конфиденциальности | URL на `privacy-policy.html` (см. `store/privacy-policy.html`, `npm run pwa:build` кладёт копию в `dist/`). |
| Дети / COPPA / семейная аудитория | Сбора данных нет; рейтинг определяется опросником Play Console. |

## Краткая формулировка для Console

> Приложение не собирает, не хранит на сервере и не передаёт персональные данные. Прогресс сохраняется локально в `localStorage` исключительно для автосохранения; сеть, аккаунты, аналитика, реклама, покупки и сторонние SDK отсутствуют.
